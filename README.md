# Bot Tracker (Rust)

Секундомер-таймер с авто-повтором интервалов. Rust-версия [Python-приложения](gui_stopwatch.pyw) на eframe/egui.

![screenshot]()

## Возможности

- Секундомер с миллисекундами (можно скрыть)
- Кнопки **СТАРТ** / **СТОП** / **СБРОС**
- После остановки — авто-повтор интервала с beep-звуком
- Обратный отсчёт до следующего повтора + прогресс-бар
- Настройки:
  - Звук (880 / 600 / 1000 Гц) + вкл/выкл
  - Убрать мс
  - Отступ (сек) — корректирует период повтора
  - Прозрачность окна (0.3–1.0)
  - Цвет отсчёта, прогресса, реакции
  - Реакция светом (вспышка фона при beep)
  - Поверх всех окон

## Управление

## Сборка

Требуется Rust (stable) и MinGW-w64.

```bash
cargo build --release
```

Или через скрипт (собирает из ASCII-пути, чтобы MinGW не ломался на кириллице):

```cmd
build.cmd
```

Готовый exe: `target/release/bot-tracker.exe`

## Запуск

```bash
bot-tracker.exe
```

Приложение без консоли (subsystem=windows). Логи пишутся в stderr — при запуске из терминала видны события (СТАРТ/СТОП/ПОВТОР).
